# Página de apoio: skills, auditoria e autonomia

Página estática (sem build) com os exercícios da formação em IA generativa para advogados. Todos os documentos em `materiais/` são fictícios, excepto os textos públicos incluídos em `Exemplos_detector.zip`.

As chaves do formador não estão neste repositório.

## Publicar na Vercel
1. Importar este repositório na Vercel.
2. Em *Root Directory*, indicar `pagina-skills`.
3. *Framework Preset*: Other. Sem *Build Command*. *Output Directory*: vazio.

Antes de publicar, preencher os marcadores `[POR PREENCHER]` em `index.html` (dia da formação, ligação do artefacto, contactos).
